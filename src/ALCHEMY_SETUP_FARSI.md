# 🔑 راهنمای کامل دریافت و تنظیم Alchemy API Key

## 📋 مراحل کامل (10 دقیقه):

---

## مرحله 1️⃣: ساخت حساب در Alchemy

### گام اول: رفتن به وبسایت Alchemy
1. به آدرس زیر بروید:
   ```
   https://dashboard.alchemy.com
   ```

2. روی دکمه **"Sign Up"** یا **"Get Started"** کلیک کنید

### گام دوم: ثبت نام
می‌توانید به یکی از روش‌های زیر ثبت نام کنید:
- **با Google:** سریع‌ترین روش
- **با GitHub:** اگر حساب GitHub دارید
- **با ایمیل:** ایمیل و پسورد وارد کنید

✅ **نکته:** Alchemy کاملاً **رایگان** است و نیازی به کارت اعتباری ندارد!

---

## مرحله 2️⃣: ساخت App در Alchemy

بعد از ورود، وارد داشبورد می‌شوید:

### گام اول: کلیک روی "Create new app"
در صفحه اصلی، یک دکمه بزرگ آبی می‌بینید با نوشته:
```
+ Create new app
```
روی آن کلیک کنید.

### گام دوم: پر کردن فرم
یک پنجره باز می‌شود. فیلدها را اینطور پر کنید:

```
┌─────────────────────────────────────────┐
│ Create App                              │
├─────────────────────────────────────────┤
│                                         │
│ App Name:                               │
│ ┌────────────────────────┐             │
│ │ Saturn Wallet          │             │
│ └────────────────────────┘             │
│                                         │
│ Chain:                                  │
│ ┌────────────────────────┐             │
│ │ Ethereum          ▼    │ ← انتخاب  │
│ └────────────────────────┘             │
│                                         │
│ Network:                                │
│ ┌────────────────────────┐             │
│ │ Ethereum Mainnet  ▼    │ ← انتخاب  │
│ └────────────────────────┘             │
│                                         │
│        [Create App]                     │
└─────────────────────────────────────────┘
```

⚠️ **خیلی مهم:**
- **Chain** باید حتماً **Ethereum** باشد (نه Polygon، نه Solana)
- **Network** باید حتماً **Mainnet** باشد (نه Sepolia، نه Goerli، نه Testnet)

### گام سوم: کلیک روی "Create App"
بعد از پر کردن فرم، روی دکمه آبی **"Create App"** کلیک کنید.

### گام چهارم: فعال کردن Ethereum Mainnet ⭐
**خیلی مهم!** بعد از ساخت App:

1. روی App کلیک کنید
2. به تب **"Networks"** بروید
3. پیدا کنید: **Ethereum** → **Mainnet**
4. روی **"Enable"** کلیک کنید

⚠️ اگر این کار را نکنید، خطای "ETH_MAINNET is not enabled" می‌گیرید!

راهنمای کامل: `/ENABLE_ETH_MAINNET.md`

## مرحله 3️⃣: دریافت API Key

### گام اول: باز کردن App
بعد از ساخت، به لیست Apps می‌روید. App جدیدتان را می‌بینید:

```
┌─────────────────────────────────────────┐
│ Apps                                    │
├─────────────────────────────────────────┤
│                                         │
│  Saturn Wallet                          │
│  Ethereum • Mainnet                     │
│  [View Details]                         │
│                                         │
└─────────────────────────────────────────┘
```

روی **"View Details"** یا روی اسم App کلیک کنید.

### گام دوم: نمایش API Key
در صفحه App، دکمه‌ای می‌بینید با نوشته:
```
🔑 API Key
```

روی آن کلیک کنید. یک پنجره popup باز می‌شود.

### گام سوم: کپی کردن API Key (⚠️ دقت کنید!)

در پنجره popup چیزی شبیه این می‌بینید:

```
┌─────────────────────────────────────────────────────────┐
│ API Endpoints                                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ HTTPS:                                                  │
│ ┌─────────────────────────────────────────────────┐   │
│ │ https://eth-mainnet.g.alchemy.com/v2/           │   │
│ │ Abc123Def456Ghi789Jkl012Mno345Pqrs678          │ 📋 │
│ └─────────────────────────────────────────────────┘   │
│                                                         │
│ WSS:                                                    │
│ ┌─────────────────────────────────────────────────┐   │
│ │ wss://eth-mainnet.g.alchemy.com/v2/             │   │
│ │ Abc123Def456Ghi789Jkl012Mno345Pqrs678          │ 📋 │
│ └─────────────────────────────────────────────────┘   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### ⚠️ **مهم‌ترین نکته:**

شما باید **فقط قسمت آخر** را کپی کنید!

#### ❌ اشتباه (کپی نکنید):
```
https://eth-mainnet.g.alchemy.com/v2/Abc123Def456Ghi789Jkl012Mno345Pqrs678
```

#### ❌ اشتباه (کپی نکنید):
```
wss://eth-mainnet.g.alchemy.com/v2/Abc123Def456Ghi789Jkl012Mno345Pqrs678
```

#### ✅ **درست (فقط این را کپی کنید):**
```
Abc123Def456Ghi789Jkl012Mno345Pqrs678
```

### چطور فقط API Key را کپی کنیم؟

**روش 1: کپی دستی**
1. روی URL کلیک کنید تا کل آن select شود
2. کپی کنید (Ctrl+C یا Cmd+C)
3. در یک Notepad یا Text Editor پست کنید
4. قسمت بعد از `/v2/` را جدا کنید
5. فقط آن قسمت را کپی کنید

**روش 2: انتخاب دقیق**
1. ماوس را روی URL ببرید
2. دقیقاً از جایی که بعد از `/v2/` شروع می‌شود کلیک کنید
3. تا آخر drag کنید
4. کپی کنید

**روش 3: استفاده از آیکون Copy**
گاهی Alchemy یک آیکون 📋 copy دارد. ولی **احتیاط کنید** - این ممکن است کل URL را کپی کند!

## مرحله 4️⃣: تنظیم در Supabase

### گام اول: رفتن به Supabase
1. به آدرس زیر بروید:
   ```
   https://supabase.com/dashboard
   ```

2. لاگین کنید

3. پروژه **Saturn Wallet** خود را پیدا کرده و باز کنید

### گام دوم: رفتن به Edge Functions Settings
1. از منوی سمت چپ، روی **"Settings"** کلیک کنید (آیکون چرخ دنده ⚙️)
2. از منوی باز شده، روی **"Edge Functions"** کلیک کنید
3. تب **"Secrets"** را باز کنید

### گام سوم: حذف Secret قدیمی (اگر وجود دارد)
اگر قبلاً یک `ALCHEMY_API_KEY` ساخته‌اید:

```
┌────────────────────────────────────────────────┐
│ Secrets                                        │
├────────────────────────────────────────────────┤
│                                                │
│  ALCHEMY_API_KEY              🗑️  ✏️         │
│  HELIUS_API_KEY               🗑️  ✏️         │
│  ...                                           │
│                                                │
└────────────────────────────────────────────────┘
```

1. روی آیکون 🗑️ کنار `ALCHEMY_API_KEY` کلیک کنید
2. در پنجره تایید، روی **"Delete"** کلیک کنید

### گام چهارم: ساخت Secret جدید
1. روی دکمه **"Add new secret"** یا **"New secret"** کلیک کنید

2. فرم را اینطور پر کنید:

```
┌─────────────────────────────────────────┐
│ Create Secret                           │
├─────────────────────────────────────────┤
│                                         │
│ Name:                                   │
│ ┌────────────────────────┐             │
│ │ ALCHEMY_API_KEY        │             │
│ └────────────────────────┘             │
│                                         │
│ Value:                                  │
│ ┌────────────────────────┐             │
│ │ Abc123Def456...        │             │
│ └────────────────────────┘             │
│                                         │
│        [Create] [Cancel]                │
└─────────────────────────────────────────┘
```

⚠️ **دقت کنید:**
- **Name** باید حتماً `ALCHEMY_API_KEY` باشد (دقیقاً همین - حتی حروف کوچک/بزرگ مهم است!)
- **Value** فقط API key است (نه URL)

3. روی **"Create"** یا **"Save"** کلیک کنید

### گام پنجم: Restart کردن Edge Function
بعضی وقت‌ها لازم است Edge Function را restart کنید:

1. از منوی چپ به **"Edge Functions"** بروید (نه Settings → Edge Functions)
2. Function به نام `make-server-e5bc10d1` را پیدا کنید
3. اگر دکمه **"Redeploy"** یا **"Restart"** دارد، روی آن کلیک کنید

## مرحله 5️⃣: صبر و تست

### صبر کنید (مهم!)
⏱️ **5 تا 10 دقیقه صبر کنید**

Supabase نیاز دارد تا:
- Secret را ذخیره کند
- Edge Function را با Secret جدید restart کند
- تغییرات را deploy کند

### تست کنید
بعد از 5-10 دقیقه:

1. به اپلیکیشن Saturn بروید
2. وارد شوید (Sign in)
3. به صفحه **Settings** بروید
4. **Dev Mode** را فعال کنید
5. پایین صفحه Settings اسکرول کنید
6. روی دکمه **"تست API Keys"** کلیک کنید

باید پیام زیر را ببینید:
```
✅ Alchemy: معتبر
```

**علت‌های ممکن:**
- [ ] URL کامل را کپی کرده‌اید (باید فقط API key باشد)

- [ ] Network در Alchemy روی Testnet است (باید Mainnet باشد)

**راه حل:**
1. Secret را دوباره delete کنید
2. دوباره با دقت بیشتر بسازید
3. 10 دقیقه کامل صبر کنید
4. تست کنید

### مشکل 2: هیچ App در Alchemy ندارم

**راه حل:**
- به https://dashboard.alchemy.com بروید
- مطمئن شوید لاگین هستید
- روی **"+ Create new app"** کلیک کنید
- مراحل بالا را دنبال کنید

### مشکل 3: API Key خیلی کوتاه است (کمتر از 20 کاراکتر)

**علت:** احتمالاً فقط قسمتی از key را کپی کرده‌اید

**راه حل:**
- دوباره به Alchemy بروید
- کل قسمت بعد از `/v2/` را با دقت کپی کنید

### مشکل 4: پیام "App suspended" می‌آید

**علت:** App در Alchemy غیرفعال شده

**راه حل:**
1. به Alchemy Dashboard بروید
2. روی App کلیک کنید
3. اگر پیام "Suspended" می‌بینید، روی "Activate" کلیک کنید
