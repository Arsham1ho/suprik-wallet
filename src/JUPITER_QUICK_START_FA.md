# 🚀 راهنمای سریع Jupiter Swap

## ⚡ شروع سریع در 3 مرحله

### 1️⃣ وارد صفحه Swap شوید
```
BottomNav → Swap 
```

### 2️⃣ انتخاب توکن‌ها
```
You pay:     SOL (باید موجودی داشته باشید)
You receive: USDC, BONK, PAI یا هر توکن دیگر
Amount:      مقدار دلخواه (مثلاً 0.1 SOL)
```

### 3️⃣ Swap کنید!
```
دکمه: 🪐 Swap on Jupiter
منتظر بمانید: 5-10 ثانیه
✅ تمام! Transaction شما روی blockchain ثبت شد
```

---

## 🎯 چک‌لیست قبل از Swap

- [ ] موجودی SOL کافی دارید؟
- [ ] حداقل 0.01 SOL برای fee نگه داشتید؟
- [ ] Banner سبز "🪐 Real On-Chain Swap" را می‌بینید؟
- [ ] Price Impact کمتر از 5% است؟
- [ ] مقدار دریافتی را بررسی کردید؟

---

## 📊 نمونه Swap

```
Input:   1 SOL
Output:  ~140 USDC
Route:   SOL → Raydium → USDC
Impact:  < 0.01%
Fee:     0.005 SOL
Time:    ~8 seconds
Status:  ✅ Confirmed on-chain
```

---

## ⚠️ نکات مهم

### ✅ انجام دهید:
- بررسی price impact
- استفاده از slippage 0.5% (پیش‌فرض)
- نگه داشتن SOL برای fee های آینده

### ❌ انجام ندهید:
- Swap تمام موجودی (SOL برای fee نگه دارید)
- نادیده گرفتن price impact بالا (> 5%)
- استفاده از slippage خیلی بالا (> 5%)

---

## 🐛 مشکلات رایج

### "Could not get price quote"
→ صبر کنید و دوباره تلاش کنید

### "Insufficient balance"
→ مقدار کمتری وارد کنید + SOL برای fee نگه دارید

### "Transaction failed"
→ Slippage را افزایش دهید (Settings)
