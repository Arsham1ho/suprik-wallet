# 🔄 راهنمای کامل Swap در Saturn

## چیست Swap؟

Swap به معنای **تبدیل یک ارز دیجیتال به ارز دیجیتال دیگر** است. مثلاً:
- SOL → USDC
- USDC → USDT
- SOL → BONK

Saturn از **Jupiter** (بهترین DEX aggregator در Solana) استفاده می‌کند تا بهترین قیمت را برای شما پیدا کند.

## چگونه Swap کنیم؟

### قدم 1: رفتن به صفحه Swap

1. اپلیکیشن Saturn را باز کنید
2. روی آیکون "Swap" در navigation پایین کلیک کنید 🔄

### قدم 2: انتخاب توکن‌ها

1. **توکن پرداختی (You Pay):**
   - روی dropdown کلیک کنید
   - توکنی که می‌خواهید بفروشید انتخاب کنید
   - فقط توکن‌هایی که در کیف پول شما موجودی دارند نمایش داده می‌شوند

2. **توکن دریافتی (You Receive):**
   - روی dropdown کلیک کنید
   - توکنی که می‌خواهید بخرید انتخاب کنید
   - می‌توانید از search box برای پیدا کردن استفاده کنید

### قدم 3: وارد کردن مبلغ

1. در قسمت "You Pay" مبلغ مورد نظر را وارد کنید
2. قیمت به صورت خودکار محاسبه می‌شود
3. مبلغ دریافتی در "You Receive" نمایش داده می‌شود

### قدم 4: بررسی جزئیات

قبل از swap، موارد زیر را بررسی کنید:

- **Exchange Rate:** نرخ تبدیل (مثلاً 1 SOL = 100 USDC)
- **Price Impact:** تأثیر swap شما بر قیمت (کمتر از 1% عالی است)
- **Estimated Fee:** هزینه تقریبی transaction
- **Route:** مسیری که Jupiter برای swap استفاده می‌کند

### قدم 5: Swap کردن!

1. روی دکمه بنفش **"Swap"** کلیک کنید
2. اگر Biometric Lock فعال باشد، تأیید کنید
3. صبر کنید تا swap تکمیل شود (معمولاً 5-10 ثانیه)
4. پیام موفقیت و signature transaction را ببینید! 🎉

## تنظیمات پیشرفته

### Slippage Tolerance

**چیست؟** حداکثر تغییر قیمتی که می‌پذیرید.

**چگونه تنظیم کنیم؟**
1. روی آیکون تنظیمات ⚙️ کلیک کنید
2. Slippage Tolerance را انتخاب کنید
3. یکی از موارد زیر را انتخاب کنید:
   - **0.1%** - برای stable coins (USDC/USDT)
   - **0.5%** - پیشنهاد شده (پیش‌فرض)
   - **1.0%** - برای volatile tokens
   - **Custom** - مقدار دلخواه

**توصیه:**
- برای SOL/USDC/USDT: 0.5%
- برای meme coins: 1-2%
- برای توکن‌های کم‌حجم: 2-5%

### Priority Fee (اختیاری)

**چیست؟** Fee اضافی برای سریع‌تر شدن transaction.

**کی استفاده کنیم؟**
- زمانی که شبکه شلوغ است
- برای swap‌های زمان‌حساس
- معمولاً نیازی نیست

## نکات مهم

### ⚠️ قبل از Swap

1. **موجودی کافی داشته باشید:**
   - مبلغ swap + هزینه transaction
   - حداقل 0.01 SOL برای rent در Solana

2. **قیمت را بررسی کنید:**
   - Exchange rate منطقی است؟
   - Price impact کمتر از 1% است؟

3. **Slippage را تنظیم کنید:**
   - برای stable coins: 0.1-0.5%
   - برای سایر توکن‌ها: 0.5-2%

### ✅ بعد از Swap

1. **Signature را ذخیره کنید:**
   - برای بررسی در blockchain explorer
   - برای رفع مشکلات احتمالی

2. **موجودی را بررسی کنید:**
   - توکن جدید اضافه شده؟
   - مبلغ صحیح است؟

3. **در Solscan بررسی کنید:**
   - به https://solscan.io بروید
   - Signature را search کنید
   - جزئیات transaction را ببینید

```

```

### تبدیل بین Stablecoins
```

USDT → USDC  (تبدیل تتر به دلار)
```

## خطاهای رایج

### ❌ "Insufficient balance"

**علت:** موجودی کافی ندارید

**راه‌حل:**
- مبلغ کمتری وارد کنید
- حداقل 0.01 SOL برای fees داشته باشید

### ❌ "No quote available"

**علت:** توکن پشتیبانی نمی‌شود یا liquidity کافی ندارد

**راه‌حل:**
- توکن دیگری انتخاب کنید
- مبلغ کمتری امتحان کنید

### ❌ "Transaction failed"

**علت:** ممکن است قیمت خیلی تغییر کرده باشد

**راه‌حل:**
1. Slippage را افزایش دهید
2. دوباره تلاش کنید
3. چند دقیقه صبر کنید

### ❌ "Price impact too high"

**علت:** مبلغ شما خیلی زیاد است و قیمت را تحت تأثیر قرار می‌دهد

**راه‌حل:**
- مبلغ کمتری swap کنید
- swap را به چند قسمت تقسیم کنید

## سوالات متداول

### Q: چقدر زمان می‌برد؟
**A:** معمولاً 5-10 ثانیه، بسته به شبکه Solana

### Q: هزینه چقدر است؟
**A:** معمولاً 0.0001-0.001 SOL (~$0.01-0.10)

### Q: می‌توانم swap را کنسل کنم؟
**A:** خیر، پس از تأیید، swap برگشت‌ناپذیر است

### Q: آیا امن است؟
**A:** بله! Saturn از Jupiter استفاده می‌کند که بهترین و امن‌ترین DEX aggregator در Solana است

### Q: حداقل مبلغ چقدر است؟
**A:** حداقل خاصی نیست، اما برای کارمزد، حداقل 0.01 SOL توصیه می‌شود

### Q: حداکثر مبلغ چقدر است؟
**A:** محدودیتی نیست، اما برای مبالغ زیاد، price impact را بررسی کنید
