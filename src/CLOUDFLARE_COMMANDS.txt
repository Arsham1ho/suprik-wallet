------------------------------------------
1️⃣ GIT SETUP
------------------------------------------

# Initialize Git (اگر نکرده‌اید)
git init

# Add all files
git add .

# Commit
git commit -m "Deploy to Cloudflare Pages"

# Create GitHub repo at: https://github.com/new
# Then:
git remote add origin https://github.com/YOUR_USERNAME/suprik-wallet.git
git branch -M main
git push -u origin main

2️⃣ LOCAL BUILD TEST
------------------------------------------

# Install dependencies
npm install

# Test build
npm run build

# Should create dist/ folder
ls -la dist/

# Preview build
npm run preview

# Open: http://localhost:4173

6️⃣ WRANGLER CLI (اختیاری)
------------------------------------------

# Install Wrangler
npm install -g wrangler

# Login
wrangler login

# Deploy directly
wrangler pages deploy dist

# This uploads dist/ to Cloudflare

------------------------------------------
7️⃣ UPDATE COMMANDS
------------------------------------------

# Make changes, then:

------------------------------------------
8️⃣ TROUBLESHOOTING COMMANDS
------------------------------------------

# Build fails? Clean install:
rm -rf node_modules package-lock.json
npm install
npm run build

# Check build output:
ls -la dist/
du -sh dist/

# Verify environment:
npm run typecheck

# Test local:
npm run preview

------------------------------------------
9️⃣ WRANGLER ADVANCED
------------------------------------------

# Create new project
wrangler pages project create suprik-wallet

# List projects
wrangler pages project list

# Deploy specific folder
wrangler pages deploy dist --project-name=suprik-wallet

# Tail logs (real-time)
wrangler pages deployment tail

# View deployments
wrangler pages deployment list

1️⃣1️⃣ CUSTOM DOMAIN SETUP
------------------------------------------

در Cloudflare Dashboard:

1. انتخاب project
2. Custom domains tab
3. Set up a custom domain
4. Enter: yourdomain.com
5. Add DNS records:

Type: CNAME
Name: @
Target: suprik-wallet-xxx.pages.dev
Proxy: Enabled (orange cloud)

------------------------------------------
1️⃣2️⃣ SECURITY HEADERS
------------------------------------------

Create file: public/_headers

Content:
/*
  X-Frame-Options: DENY
  X-Content-Type-Options: nosniff
  Referrer-Policy: no-referrer
  Permissions-Policy: geolocation=(), microphone=(), camera=()

/sw.js
  Service-Worker-Allowed: /
  Content-Type: application/javascript

/manifest.json
  Content-Type: application/manifest+json

------------------------------------------
1️⃣3️⃣ REDIRECTS
------------------------------------------

Create file: public/_redirects

Content:
/* /index.html 200

# Or specific redirects:
/old-url /new-url 301
