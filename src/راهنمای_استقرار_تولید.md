## 🔧 اگر بعد از Deploy مشکلی بود؟

### مشکل 1: هنوز Demo Mode نشان می‌دهد

**علت محتمل:**
- DNS propagation delay (5-10 دقیقه صبر کنید)
- یا Supabase Edge Function هنوز محدودیت دارد

**راه حل:**
```
✅ Layer 2 (Direct API) کار خواهد کرد
✅ خارج از iframe هیچ CORS issue نیست
✅ Swaps باز هم Real هستند
```

### مشکل 2: Transaction fail می‌شود

**علت محتمل:**
- موجودی کافی نیست
- Network congestion
- Slippage کم است

**راه حل:**
```
1. Balance را چک کنید
2. مقدار کمتری امتحان کنید
3. Slippage را افزایش دهید (0.5% → 1%)
4. دوباره try کنید
```
