## 🎯 تست 1: ارسال توکن (Send)

### هدف: بررسی ارسال واقعی SOL روی Solana Mainnet

### پیش‌نیازها:
- ✅ حساب کاربری ساخته شده
- ✅ حداقل 0.1 SOL موجودی (برای تست)

### مراحل تست:

#### مرحله 1: آماده‌سازی موجودی
```
1. وارد Home شوید
2. کلیک روی Settings (پایین صفحه)
3. کلیک روی "Dev Mode"
4. فعال کردن Dev Mode
5. کلیک "Quick Receive"
6. انتخاب SOL
7. مبلغ: 1
8. کلیک Receive
9. ✅ انتظار: موجودی SOL افزایش یابد
10. بازگشت به Home
```

#### مرحله 2: شروع ارسال
```
11. کلیک روی دکمه "Send" در Home
12. ✅ انتظار: صفحه "Select Token" باز شود
13. کلیک روی SOL
14. ✅ انتظار: رفتن به صفحه "Enter Address"
```

#### مرحله 3: وارد کردن آدرس
```
15. وارد کردن یک آدرس معتبر Solana:
    مثال: CWvFSW6gFYi7KaSpAWA1DvWJvxkCrMV1ZdMphBKXhPdX
    
16. ✅ انتظار: نمایش چک سبز (address valid)
17. ✅ انتظار: نمایش "Solana" network
18. کلیک Continue
19. ✅ انتظار: رفتن به صفحه "Enter Amount"
```

#### مرحله 4: وارد کردن مبلغ
```
20. وارد کردن مبلغ: 0.1
21. ✅ انتظار: نمایش Fee: 0.001 SOL (0.5%)
22. ✅ انتظار: نمایش Total: 0.101 SOL
23. ✅ انتظار: دکمه Continue فعال باشد
24. کلیک Continue
25. ✅ انتظار: رفتن به صفحه "Review"
```

#### مرحله 5: بررسی و تایید
```
26. بررسی اطلاعات:
    - From: Your wallet
    - To: CWvF...hPdX
    - Amount: 0.1 SOL
    - Fee: 0.001 SOL
    - Total: 0.101 SOL
    
27. ✅ انتظار: همه اطلاعات درست باشد
28. کلیک "Send Now"
```

#### مرحله 6: پردازش تراکنش
```

30. ✅ انتظار: نمایش loading spinner
31. صبر کنید 2-5 ثانیه

33. ✅ انتظار: نمایش Transaction Signature
34. ✅ انتظار: امکان کپی signature
```

#### مرحله 7: بررسی نتایج
```
35. بازگشت اتوماتیک به Home بعد از 3 ثانیه
36. ✅ بررسی: موجودی SOL کاهش یافته؟
    - قبل: 1.000 SOL
    - بعد: ~0.899 SOL (1 - 0.1 - 0.001 = 0.899)
    
37. کلیک روی Activity (پایین صفحه)
38. ✅ بررسی: آیا تراکنش جدید نمایش داده می‌شود؟
39. کلیک روی تراکنش
40. ✅ بررسی: جزئیات کامل نمایش داده می‌شود؟
41. کلیک "View on Solscan"
42. ✅ بررسی: تراکنش در Solscan قابل مشاهده است؟
```
