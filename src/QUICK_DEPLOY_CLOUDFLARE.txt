==========================================
  مشکل؟
==========================================

Build failed:
→ Build log را چک کنید
→ Environment Variables را چک کنید

صفحه سفید:
→ Console error ببینید (F12)
→ Environment Variables را چک کنید

404 on routes:
→ فایل _redirects در dist هست؟
→ احتمالاً fix شده!
