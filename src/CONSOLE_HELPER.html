🔧 Saturn Admin Console Helper

ابزار کمکی برای مدیریت Admin ها

۱. دریافت Wallet ID فعلی

برای دریافت Wallet ID کاربر فعلی، این دستور را در Console مرورگر اجرا کنید:

console.log('Current Wallet ID:', localStorage.getItem('wallet_id'));

۲. دریافت تمام Wallet ID ها

برای مشاهده تمام Wallet ID های ذخیره شده در localStorage:

Object.keys(localStorage) .filter(key => key.includes('wallet')) .forEach(key => console.log(key, localStorage.getItem(key)));

۳. اضافه کردن به لیست Admin

1 کپی Wallet ID: از بخش بالا Wallet ID را کپی کنید
2 باز کردن فایل: /utils/adminCheck.ts
3 اضافه کردن: Wallet ID را به آرایه ADMIN_WALLET_IDS اضافه کنید
const ADMIN_WALLET_IDS = [ 'your-wallet-id-here', // 👈 اینجا اضافه کنید ];
💡 نکته: بعد از اضافه کردن Admin جدید، حتماً اپ را رفرش کنید.

۴. بررسی وضعیت Admin

برای بررسی اینکه آیا کاربر فعلی Admin است:

// در Console اپ import { isAdmin } from './utils/adminCheck'; console.log('Am I admin?', isAdmin(localStorage.getItem('wallet_id')));
⚠️ هشدار: این بررسی فقط در محیط Development کار می‌کند. در Production باید از Settings → Developer → Admin Panel استفاده کنید.

۵. مثال کامل

برای اضافه کردن Admin جدید، این مراحل را دنبال کنید:

// مرحله 1: دریافت Wallet ID const walletId = localStorage.getItem('wallet_id'); console.log('Wallet ID:', walletId); // مرحله 2: کپی کنید // مرحله 3: به /utils/adminCheck.ts اضافه کنید const ADMIN_WALLET_IDS = [ 'wallet-id-شما', ]; // مرحله 4: ذخیره و رفرش // مرحله 5: تست // Settings → Developer → Admin Panel

🐛 عیب‌یابی

مشکل: بخش "Developer" نمایش داده نمی‌شود
راه‌حل:
  • Wallet ID را چک کنید
  • لیست Admin ها را بررسی کنید
  • اپ را رفرش کنید
مشکل: Admin Panel باز نمی‌شود
راه‌حل:
  • کلمه "adm" را دقیق تایپ کنید
  • ۱۲ بار تایپ کنید (نه کمتر، نه بیشتر)
  • در صورت اشتباه، از اول شروع می‌شود
