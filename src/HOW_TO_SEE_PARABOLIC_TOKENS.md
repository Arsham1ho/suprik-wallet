# 🎯 How to See Your Parabolic AI Tokens (Quick Guide)

## The #1 Most Common Issue: Wrong Network Mode ⚠️

**If you sent Parabolic AI tokens on Solana MAINNET**, you need to turn OFF Testnet Mode!

---

## ✅ Quick Fix (Takes 10 seconds)

### Step 1: Check Network Mode
1. Open Saturn Wallet
2. Tap **Settings** (bottom right)
3. Tap **Developer**
4. Look at **"Testnet Mode"**

**Is it ON?** → Turn it **OFF** ✅
**Is it OFF?** → Keep it OFF ✅

### Step 2: Refresh
1. Go back to **Home** (bottom left)
2. Tap the **refresh icon** (🔄) at the top
3. Wait 5-10 seconds

### Step 3: Check Again
Your Parabolic AI tokens should now appear! 🎉

---

## 🔍 Still Not Showing? Use Balance Checker

### Use the Built-in Debug Tool:

1. **Settings** → **Developer** → **Balance Checker**
2. Tap **"Check All Balances"**
3. Wait 10-20 seconds

You'll see:
- ✅ Your exact Solana address
- ✅ ALL tokens on that address (including PARAI)
- ✅ Link to view on Solana Explorer

### Example Output:
```
📊 Solana (Mainnet)
Address: 7xK8...9sPq
Balance: 0.5 SOL

Tokens Found:
✅ Parabolic AI (PARAI): 1,000 tokens
✅ USDC: 50 tokens
```

If you see it here but not on Home screen → Wait 30 seconds and refresh Home

---

## 🌐 Verify on Blockchain Explorer

### Double-Check on Solana Explorer:

1. In Balance Checker, tap **"View on Solana Explorer"**
2. This opens the blockchain explorer
3. Click the **"Tokens"** tab
4. Look for **Parabolic AI**

**If you see it on Explorer** → The tokens ARE in your wallet!
- Just need to refresh the app
- Or wait for auto-refresh (happens every 10 seconds)

**If you DON'T see it on Explorer** → The transaction may have failed
- Check the transaction signature from the sender
- Verify the correct wallet address was used

Go through this list:

- [ ] **Testnet Mode is OFF** (for mainnet tokens)
- [ ] **Waited at least 1 minute** after receiving tokens
- [ ] **Tapped the refresh button** on Home screen

- [ ] **Checked Solana Explorer** to confirm on blockchain

## 🔄 How Auto-Refresh Works

Saturn Wallet automatically refreshes your balance **every 10 seconds** (just like Phantom!).

So if tokens were just sent to you:
1. Wait 30-60 seconds for blockchain confirmation
2. The wallet will auto-detect them
3. They'll appear on the Home screen

**No manual action needed** - it just works! ✨

---

## 🆘 Still Having Issues?

### Check These:

1. **API Keys**: Make sure Helius API Key is set
   - Settings → Developer → API Keys
   - Add your Helius API key
   - Get one free at: https://helius.dev

2. **Browser Console**: Press F12 and check for errors
   - Look for messages like `[Solana] ✅` (good) or `[Solana] ❌` (bad)

3. **Transaction Status**: Ask the sender for the transaction signature
   - Check it on https://explorer.solana.com
