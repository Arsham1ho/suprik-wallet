# 📡 قابلیت P2P Transfer - خلاصه به فارسی

## 🎯 چی کار کردیم؟

صفحه **Chat** را با یک سیستم **P2P Offline Transfer** جایگزین کردیم که خیلی کاربردی‌تر و نوآورانه‌تر است!

---

## ✨ قابلیت‌های جدید

### 1. **ساخت تراکنش آفلاین**
- تراکنش بسازید بدون نیاز به اینترنت
- با کلید خصوصی دستگاه امضا می‌شود
- 100% آفلاین کار می‌کند

### 2. **روش‌های مختلف اشتراک‌گذاری**
- 📱 **QR Code**: نمایش QR برای اسکن
- 📁 **فایل**: دانلود و آپلود `.json`
- 🔵 **Bluetooth**: اشتراک از طریق بلوتوث (به زودی)
- 📶 **NFC**: اشتراک با تپ NFC (به زودی)
- 📤 **Share API**: از منوی Share دستگاه

### 3. **تایید آفلاین**
- امضای تراکنش رو آفلاین بررسی کنید
- اعتبار تراکنش رو چک کنید
- نیازی به اینترنت نیست

### 4. **پخش هوشمند**
- وقتی آنلاین شدید blockhash آپدیت می‌شه
- تراکنش به بلاکچین ارسال می‌شود
- اگه آفلاینید، صبر می‌کنه

---

## 🚀 چطور کار می‌کنه؟

### برای فرستنده:

1. **وارد صفحه P2P بشید**
   - روی آیکون P2P در نوار پایین بزنید

2. **تب "Send" رو انتخاب کنید**
   - آدرس گیرنده رو وارد کنید
   - مقدار رو بنویسید
   - روی "Sign Transaction" بزنید

3. **تراکنش رو به اشتراک بذارید**
   - **QR Code**: کد QR رو نشون بدید
   - **فایل**: فایل رو دانلود و ارسال کنید
   - **Bluetooth/NFC**: از طریق دستگاه بفرستید

### برای گیرنده:

1. **وارد صفحه P2P بشید**
   - روی آیکون P2P بزنید

2. **تب "Receive" رو انتخاب کنید**
   - QR Code رو اسکن کنید
   - یا فایل تراکنش رو آپلود کنید

3. **تایید و پخش**
   - تراکنش به صورت خودکار تایید می‌شه
   - وقتی آنلاین شدید، روی "Broadcast" بزنید
   - منتظر تایید باشید
   - تموم! 🎉

## 📱 روش‌های اشتراک‌گذاری

### QR Code
```
✅ بهترین برای: پرداخت حضوری
✅ کار می‌کنه: آفلاین
✅ سرعت: فوری
✅ محدوده: دید چشمی
```

### فایل
```
✅ بهترین برای: انتقال از راه دور
✅ کار می‌کنه: آفلاین  
✅ سرعت: سریع
✅ محدوده: نامحدود (از طریق هر اپی)
```

### Bluetooth
```
✅ بهترین برای: انتقال نزدیک
✅ کار می‌کنه: آفلاین
✅ سرعت: متوسط
✅ محدوده: ~10 متر
⚠️ وضعیت: به زودی
```

### NFC
```
✅ بهترین برای: پرداخت با تپ
✅ کار می‌کنه: آفلاین
✅ سرعت: خیلی سریع
✅ محدوده: فاصله لمس
⚠️ وضعیت: به زودی
```

## 💡 مثال‌های کاربردی

### مثال 1: پرداخت در کافی‌شاپ
```
1. مشتری تراکنش 0.01 SOL می‌سازه
2. QR کد رو به فروشنده نشون می‌ده
3. فروشنده اسکن می‌کنه
4. آفلاین تایید می‌شه
5. وقتی آنلاین شد پخش می‌شه
✅ پرداخت انجام شد!
```

### مثال 2: حواله خانوادگی
```
1. کاربر A تراکنش 10 SOL می‌سازه
2. فایل تراکنش رو دانلود می‌کنه
3. از طریق واتساپ به کاربر B می‌فرسته
4. کاربر B فایل رو آپلود می‌کنه
5. تایید و پخش می‌کنه
✅ پول دریافت شد!
```

### مثال 3: انتقال اضطراری
```
1. در منطقه بدون اینترنت
2. تراکنش امضا شده بسازید
3. در گوشی ذخیره کنید
4. به منطقه با اینترنت برید
5. تراکنش رو پخش کنید
✅ وجه منتقل شد!
```

| ویژگی | Chat | P2P Transfer |

| **کاربرد** | پیام‌رسانی | اشتراک تراکنش |
| **نوآوری** | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| **پشتیبانی آفلاین** | ❌ | ✅ |
| **کاربرد عملی** | محدود | بالا |
| **امنیت** | مبتنی بر سرور | سمت کلاینت |
| **حریم خصوصی** | متوسط | حداکثر |
| **منحصر به فرد بودن** | رایج | نادر |
| **تقاضای کاربر** | کم | زیاد |
