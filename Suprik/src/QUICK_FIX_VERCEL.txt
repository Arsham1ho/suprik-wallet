گام 1: حذف پروژه و Import مجدد
------------------------------------------

1. به Vercel Dashboard بروید
   👉 https://vercel.com/dashboard

2. پروژه خود → Settings

3. پایین صفحه: "Delete Project"

4. تایپ کنید نام پروژه و Delete

5. Dashboard → "Add New" → "Project"

6. Repository را Import کنید


گام 2: تنظیمات Build
------------------------------------------

Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
Install Command: npm install
Root Directory: ./

==========================================
  اگر هنوز خطا داد
==========================================

1. چک کنید این فایل‌ها در GitHub هستند:
   - package.json
   - vite.config.ts
   - index.html
   - main.tsx
   - vercel.json

2. اگر نیستند:
   git add .
   git commit -m "Add build files"
   git push origin main

3. در Vercel → Redeploy
