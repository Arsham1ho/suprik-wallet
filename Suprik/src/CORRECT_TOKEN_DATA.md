## 🔢 Supply Types Explained

### **Fixed Supply** (مثل Bitcoin):
```
Total Supply = Max Supply = 21,000,000 BTC
Circulating Supply < Total Supply (در حال mining)
```

### **Inflationary** (مثل Solana):
```
Total Supply = در حال افزایش
Max Supply = null (نامحدود)
Inflation Rate = کاهشی (starting ~8%, target ~1.5%)
```

### **Backed** (مثل USDC):
```
Total Supply = مقدار USD در reserve
Max Supply = null (بر اساس تقاضا)
Supply = 100% backed by reserves
```

### **Burned/Deflationary** (مثل ETH بعد از EIP-1559):
```
New Supply = Block rewards
Burned = Transaction fees
Net = می‌تواند inflationary یا deflationary باشد
```
