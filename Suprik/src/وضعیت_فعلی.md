## چه کاری باید انجام دهم؟

### فقط یک کار: اضافه کردن API Keys

دو روش وجود دارد:

#### روش 1: از داخل اپ (آسان‌تر)
```
Settings → Developer → API Keys
```
در آنجا می‌توانید این کلیدها را اضافه کنید:
- Helius API Key (برای Solana)
- Alchemy API Key (برای Ethereum)

#### روش 2: در کد (برای توسعه‌دهندگان)
```bash
# فایل .env
HELIUS_API_KEY=your_helius_api_key
ALCHEMY_API_KEY=your_alchemy_api_key
```

### چطور API Keys بگیرم؟

**Helius** (برای Solana):
1. برو به [helius.dev](https://helius.dev)
2. ثبت‌نام کن (رایگان)
3. یک project بساز
4. API key رو کپی کن

**Alchemy** (برای Ethereum):
1. برو به [alchemy.com](https://alchemy.com)
2. ثبت‌نام کن (رایگان)
3. یک app بساز
4. API key رو کپی کن

الان می‌توانی با توکن‌های تستی کار کنی بدون خرج پول واقعی!

### 2. Balance Checker

این ابزار به تو نشان می‌دهد:
- موجودی واقعی هر blockchain
- آدرس دقیق wallet
- لینک به Block Explorer

6. ارسال کن
7. تراکنش را در Block Explorer ببین

## مشکلات رایج و راه‌حل

### ❌ موجودی نمایش داده نمی‌شود
**راه‌حل**: 
1. Settings → Developer → API Keys
2. API keys را وارد کن
3. صفحه را Refresh کن

### ❌ Swap کار نمی‌کند
**راه‌حل**:
1. مطمئن شو Helius API Key وارد شده
2. حداقل موجودی SOL داشته باش (برای Fee)
3. از Testnet Mode استفاده کن برای تست

### ❌ Transaction Failed
**راه‌حل**:
1. بررسی کن موجودی کافی داری
2. بررسی کن آدرس صحیح است
3. بررسی کن Fee کافی است
4. از Balance Checker استفاده کن
