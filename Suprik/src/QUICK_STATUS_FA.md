## ✅ واقعی | ❌ شبیه‌سازی

### ✅ REAL (واقعی)
```
قیمت‌ها          → از CoinGecko API (هر 30 ثانیه بروزرسانی)
SOL ارسال        → On-chain واقعی (با 0.5% کارمزد)
SOL دریافت       → On-chain واقعی
توکن PAI         → وجود دارد در CoinGecko
تاریخچه SOL      → از blockchain واقعی
```

### ❌ SIMULATED (شبیه‌سازی)
```
Swap عملیات      → فقط در database
PAI خرید/فروش   → شبیه‌سازی شده
ETH/BTC موجودی   → فقط در database
Dev Mode         → 100% شبیه‌سازی برای تست
```

// مثال: SOL → PAI

  inputMint: 'SOL',
  outputMint: 'PAI',
  amount: 1000000, // 1 SOL
