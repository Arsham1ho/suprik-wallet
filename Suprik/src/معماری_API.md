## 📊 پیکربندی فعلی API

### ✅ **شبکه‌های فعال**

#### 🟣 Solana (فعال)
- **ارائه‌دهنده RPC**: Helius
- **کلید API**: `HELIUS_API_KEY` ✅ پیکربندی شده

  - Mainnet: `https://mainnet.helius-rpc.com/?api-key=${HELIUS_API_KEY}`

  - ✅ موجودی SOL اصلی از طریق متد `getBalance`

  - نسخه رایگان: ~100 درخواست در ثانیه
  - نسخه پریمیوم: محدودیت‌های بالاتر (در صورت ارتقا)
- **وضعیت**: 🟢 کاملاً کاربردی

## 🔐 مدیریت کلیدهای API

### متغیرهای محیطی

کلیدهای API زیر به عنوان secrets در Supabase ذخیره شده‌اند:

| متغیر | هدف | وضعیت | لازم برای |
|-------|------|--------|-----------|
| `HELIUS_API_KEY` | دسترسی RPC سولانا | ✅ فعال | موجودی‌ها، توکن‌ها، swap های سولانا |
| `ALCHEMY_API_KEY` | RPC چندزنجیره‌ای | ✅ تنظیم شده، غیرفعال | اتریوم، Base، Polygon (هنگام فعال‌سازی) |
| `APP_FEE_WALLET` | جمع‌آوری کارمزد | ✅ تنظیم شده | کارمزدهای تراکنش |
| `RESEND_API_KEY` | سرویس‌های ایمیل | ✅ تنظیم شده | تأیید ایمیل (در صورت استفاده) |

### امنیت

- ✅ **کلیدهای API فقط در سمت سرور ذخیره می‌شوند** (در Edge Functions سوپابیس)
- ✅ **هرگز به frontend منتقل نمی‌شوند** (در environment variables نگهداری می‌شوند)
- ✅ **کلاینت با anon key سوپابیس احراز هویت می‌کند** (دسترسی فقط خواندنی)
- ✅ **سرور همه درخواست‌ها را اعتبارسنجی می‌کند** قبل از فراخوانی API های خارجی

## 📡 جزئیات API سولانا (Helius)

### چرا Helius؟

1. **🚀 کارایی بالا**: 
   - نودهای RPC فوق‌سریع
   - SLA با 99.9% uptime
   - توزیع CDN جهانی

2. **📦 DAS API (استاندارد دارایی دیجیتال)**:
   - دریافت متادیتای توکن به صورت فوری
   - نیازی به تجزیه داده‌های on-chain نیست
   - پشتیبانی غنی از متادیتای NFT

3. **💰 نسخه رایگان سخاوتمندانه**:
   - 100 درخواست در ثانیه
   - فراخوانی‌های نامحدود getBalance
   - عالی برای نمونه‌سازی

4. **🔧 سازگار با توسعه‌دهنده**:
   - مستندات عالی
   - پشتیبانی WebSocket
   - API های تاریخچه تراکنش

### متدهای Helius مورد استفاده

```typescript
// 1. دریافت موجودی SOL اصلی
{
  jsonrpc: '2.0',
  method: 'getBalance',
  params: [address]
}

// 2. دریافت اکانت‌های توکن SPL
{
  jsonrpc: '2.0',
  method: 'getTokenAccountsByOwner',
  params: [
    address,
    { programId: 'TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA' },
    { encoding: 'jsonParsed' }
  ]
}

// 3. دریافت متادیتای توکن (DAS API)
{
  jsonrpc: '2.0',
  method: 'getAsset',
  params: { id: mintAddress }
}

// 4. دریافت امضاهای تراکنش
{
  jsonrpc: '2.0',
  method: 'getSignaturesForAddress',
  params: [address, { limit: 10 }]
}
```

### زمان پاسخ

| عملیات | میانگین تأخیر | یادداشت‌ها |
|--------|--------------|------------|
| دریافت موجودی SOL | ~200-500ms | فراخوانی مستقیم RPC |
| دریافت توکن‌های SPL | ~800ms-1.5s | چند اکانت + متادیتا |
| دریافت تاریخچه تراکنش | ~400-700ms | امضاهای cache شده |
| ارسال تراکنش | ~1-2s | تأیید شبکه |
